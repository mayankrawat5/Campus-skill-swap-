# Campus Skill Swap Network

Campus Skill Swap Network is our PBL project based on the idea of
students helping each other learn new skills.

In a college, different students have different skills. For example,
one student may know C++, another may know graphic designing, while
someone else may be good at video editing or public speaking. The
problem is that students often don't know who can help them learn a
particular skill.

Our project aims to make it easier for students to find such people
and exchange skills with each other.

## What is the idea?

A student can add:

- Skills they can teach
- Skills they want to learn
- Learning preferences
- Other relevant information

The system can then find students who are suitable learning partners.

For example:

```text
Student A knows C++ and wants to learn Python
Student B knows Python and wants to learn C++
